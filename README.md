# K'Osez BLOSSOM

K'Osez BLOSSOM is a language-learning workspace built from the supplied Grok workspace.

## Repository

The application source is tracked directly in this repository on `main`.

Core areas include:

- `src/` — application UI, routes, business logic and BLOSSOM engine
- `server/` — server-side middleware and integrations
- `migrations/` — database migrations
- `public/` — static assets and installation resources
- `.grok/` — workspace skills and project references
- `scripts/` — development, validation and migration tooling

Generated/cache output and transfer archives are not part of the tracked source tree.
