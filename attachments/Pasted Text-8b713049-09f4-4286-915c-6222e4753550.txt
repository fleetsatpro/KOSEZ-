2.1 Full Pron’Lab — Complete Spec
User Stories + Acceptance Criteria
PRON-2.1 Longitudinal History
As a learner I practise the same item across sessions and see my improvement.
AC: Every attempt stored. Learner can open any item and see score history + audio history (last 10 attempts minimum). Simple sparkline or list of scores over time.
PRON-2.2 Specific Feedback
As a learner I receive actionable visual + audio feedback.
AC: Model audio + my audio side-by-side. Highlighted problem segment when possible. One clear tip in Léo’s voice. Score shown but secondary.
PRON-2.3 Progression Path
As a learner I move from sounds → words → sentences → short spontaneous speech.
AC: Clear unlock rules. Learner can always go back. “Mastery” flag when 3 consecutive attempts ≥ threshold.
PRON-2.4 Teacher View
As a teacher I see pronunciation flags before class.
AC: Per-class list sorted by need. One-click “assign remediation set” of 5–8 items.
PRON-2.5 Export
As a learner I can export a 20-second before/after clip.
AC: Consent toggle. Download or share link. Only my own audio.
Data Model
pronlab_items (
  id, language, type ('phoneme'|'word'|'sentence'|'spontaneous'),
  text, phonemes[], model_audio_url, level, difficulty, tags[]
)

pronlab_attempts (
  id, learner_id, item_id, audio_url,
  overall_score, segment_scores jsonb, feedback jsonb,
  created_at
)

pronlab_progress (
  learner_id, item_id, best_score, attempt_count,
  mastery_reached_at, last_attempt_at
)
API
GET  /pronlab/items?language=&level=&type=
GET  /pronlab/items/:id
POST /pronlab/attempts          (audio + item_id)
GET  /pronlab/progress
GET  /pronlab/history/:itemId
POST /pronlab/assign            (teacher)
GET  /teacher/pronlab/flags
2.2 Language Tandem — Complete Spec
User Stories + AC
TANDEM-1 Profile & Request
As a learner I create a tandem profile and request.
AC: Languages I speak + languages I want, level band, 3–5 interests, availability windows, goals. Can pause/cancel.
TANDEM-2 Matching
As a learner I receive ranked compatible partners.
AC: Score based on language direction, level proximity (±1 band), shared interests, overlapping availability. Both sides must accept.
TANDEM-3 Structured Session
As a learner I enter a timed 30+30 (or flexible) session with prompts.
AC: Visible timer. Prompt deck changes or on-demand. Equal time enforced by default. End session early possible.
TANDEM-4 Private Debrief
As a learner I receive a short private AI debrief.
AC: One strength + one improvement in my target language. No comparison with partner. Optional.
TANDEM-5 Safety
As a learner I can report, block, or leave instantly.
AC: One-tap report. Block removes future matching. Repeated reports escalate.
Data
tandem_profiles, tandem_requests, tandem_matches,
tandem_sessions (with start/end, language_split, prompt_log),
tandem_feedback
API
POST/GET /tandem/profile
POST     /tandem/requests
GET      /tandem/matches
POST     /tandem/matches/:id/accept
POST     /tandem/sessions
POST     /tandem/sessions/:id/end
POST     /tandem/feedback
POST     /tandem/report
2.3 Teacher Studio — Complete Spec
User Stories + AC
TEACH-1 Prep View
As a teacher I open a class and immediately see who needs attention.
AC: Students listed with flags (pronunciation, grammar, participation, low speaking volume, missed missions). One-click generate 6-minute warm-up.
TEACH-2 Quick Capture
As a teacher I tag or voice-note a student in < 30 seconds.
AC: Predefined tags + free text. Voice note auto-transcribed. Works on mobile.
TEACH-3 Auto Follow-up
As a teacher AI drafts personalised homework + progress note.
AC: I can edit or discard before it is sent to the learner. Learner receives it inside the app under LEARN or MOI.
TEACH-4 Roster Overview
As a teacher I see all my learners with stage, speaking minutes, last activity, Pron’Lab status.
AC: Sortable, filterable, no vanity metrics.
Data
teacher_classes, class_enrollments,
teacher_notes, homework_assignments,
teacher_flags (materialised from activity + pronlab)
API
GET  /teacher/classes
GET  /teacher/classes/:id/prep
POST /teacher/notes

GET  /teacher/roster
